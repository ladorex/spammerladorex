# NGL Spam Bot
Bu, NGL (Not Gonna Lie) platformunda, belirli bir kullanıcı adına spam mesajı göndermek için geliştirilmiş bir Python botudur. Bot, rastgele kullanıcı ajanları kullanarak daha doğal görünmesini sağlar ve gönderimlerinizi hızla gerçekleştirir.

## Özellikler
Rastgele User-Agent Seçimi: Bot her istek gönderdiğinde rastgele bir User-Agent seçer, böylece bot daha az tespit edilir.

Mesaj Gönderimi: Belirtilen kullanıcı adına mesaj gönderebilirsiniz.

Her Cihaz için Farklı ID: Her istekte benzersiz bir cihaz ID’si kullanarak spam atmayı daha güvenli hale getirir.

Renkli Konsol Çıktısı: pystyle modülü kullanarak renkli metin çıkışı sağlar.

### Gereksinimler
Python 3.6+

requests modülü

pystyle modülü

Bu modülleri yüklemek için şu komutları kullanabilirsiniz:
`pip install -r moduller.txt`
